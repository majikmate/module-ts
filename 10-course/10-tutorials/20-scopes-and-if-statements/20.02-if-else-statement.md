# if Statement

```typescript
if (expression) {
    statement;
    statement;
    ...
} else {
    statement;
    statement;
    ...
}
```

## Example

```typescript
const age = 16;

if (age >= 18) {
    console.log("You are an adult.");
    console.log("You can vote.");
} else {
    console.log("You are a minor.");
    console.log("You cannot vote yet.");
}
```

In this example:

- `age >= 18` is the **expression**
- The statements in the `if` block execute when the expression is `true`
- The statements in the `else` block execute when the expression is `false`
