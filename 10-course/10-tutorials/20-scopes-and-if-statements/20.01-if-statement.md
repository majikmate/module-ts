# if Statement

```typescript
if (expression) {
    statement;
    statement;
    ...
}
```

## Example

```typescript
const age = 18;

if (age >= 18) {
    console.log("You are an adult.");
    console.log("You can vote.");
}
```

In this example:

- `age >= 18` is the **expression**
- `console.log("You are an adult.");` and `console.log("You can vote.");` are
  the **statements**
