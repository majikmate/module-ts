# if Anweisungen

```typescript
if (expression) {
    statement;
    statement;
    ...
} else if (expression) {
    statement;
    statement;
    ...
} else {
    statement;
    ...
}
```

## Example

```typescript
const grade = 75;

if (grade >= 90) {
    console.log("Excellent!");
    console.log("Grade: A");
} else if (grade >= 75) {
    console.log("Good job!");
    console.log("Grade: B");
} else {
    console.log("Keep trying!");
    console.log("Grade: C or lower");
}
```

In this example:

- `grade >= 90` is the first **expression** that is checked
- If false, `grade >= 75` is the second **expression** that is checked
- If both are false, the `else` block executes
- Only one of the three blocks will execute
