# Zeichenketten und Zahlen

```typescript
let appleAverageWeight = 0.19;
let applesPricePerkg = 3.99;

let applesPerKg = 1 / appleAverageWeight;

console.log("20kg apples cost: " + applesPricePerkg * 17);
console.log("With 20kg apples you get about " + applesPerKg * 20 + " apples");
```

## Alternative mit Template Strings

Template Strings (auch Template Literals genannt) bieten eine modernere und
lesbarere Art, Werte in Strings einzufügen:

```typescript
let appleAverageWeight = 0.19;
let applesPricePerkg = 3.99;

let applesPerKg = 1 / appleAverageWeight;

console.log(`20kg apples cost: ${applesPricePerkg * 17}`);
console.log(`With 20kg apples you get about ${applesPerKg * 20} apples`);
```

**Vorteile von Template Strings:**

- Verwendung von Backticks `` ` `` statt Anführungszeichen `"`
- Ausdrücke werden mit `${...}` direkt in den String eingefügt
- Keine `+` Operatoren nötig zum Verbinden von Strings
- Bessere Lesbarkeit, besonders bei mehreren Variablen
