# Arrays & for of loop

```typescript
// calculate the sum of the values 1, 2, 3, 4, ...

// declare the array
const numbers = [1, 2, 3, 4];

// add additional values to the numbers array
numbers.push(17);
numbers.push(22);

// delcare the sum variable
let sumOfNumbers = 0;

// iterate over all array elements and calculate the sum
for (const num of numbers) {
    sumOfNumbers = sumOfNumbers + num;
}

// print the sum of numbers to the console
console.log(`The sum of the numbers ${numbers} is ${sumOfNumbers}`);
```
